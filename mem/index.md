# Project Memory

## Core
App is "Kanso" — a simple, private task manager (login, tasks with due dates, dashboard). Backend on Lovable Cloud.
Design: warm off-white bg, deep teal primary, amber accent. Font Plus Jakarta Sans. Calm/minimal, no purple. Use semantic tokens in src/styles.css only.
Auth: email/password + Google. Tasks/profiles are per-user (RLS by auth.uid()).
